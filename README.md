# adityadhanawade.github.io

Personal portfolio site for Aditya Dhanawade, full-stack web developer (Next.js/React) and UI/UX designer, based in Pune.

Live at [adityadhanawade.github.io](https://adityadhanawade.github.io/).

## Stack

- [Vite](https://vite.dev/) + React + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/)
- [React Three Fiber](https://r3f.docs.pmnd.rs/) / [drei](https://github.com/pmndrs/drei) for the 3D hero scene
- [Framer Motion](https://motion.dev/) for scroll reveals, tilt cards, and magnetic buttons

## Development

```bash
npm install
npm run dev
```

## Deployment

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds the site and publishes `dist/` to GitHub Pages via GitHub Actions.
